How to read this report

Unavailable means collection did not supply evidence. 0 is shown only when an eligible collector returned zero records. Incomplete preserves returned data but flags a shorter window, limit or error.

Start with readable exports and the field guide. Nested fields are expanded, lists are line-separated, and resolved IDs retain their original identifier. Raw JSON remains available for full rule interpretation.

UPNs and URLs are displayed when returned. Concealed identities cannot be reconstructed; blank owners and missing data are not guessed. Service principal counts are not agent counts.
